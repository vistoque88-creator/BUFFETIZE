# Buffet Ize – site

Site do Buffet Ize (buffet, restaurante e rotisseria), Jaboticabal - SP. Publicado em https://buffetize.com.br pelo GitHub Pages.

- `index.html`: o site (gerado a partir de `fonte/pagina.html` com `python3 fonte/montar.py`).
- `cardapio.json`: cardápio do dia das marmitas.
- `img/`: logo e fotos.
